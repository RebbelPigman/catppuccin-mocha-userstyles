# Catppuccin Mocha userstyles

Stylus userstyles for Kick, Rumble, YouTube, YouTube Music, Google, Teams, OneDrive, GitHub, Grok, Discord, Spotify, QuillBot, Claude, DuckDuckGo, Stylus, and Proton. Mocha base `#1e1e2e`, peach primary, mauve links/chips, sky channel names.

**Upstream base:** site themes are checked against and often adapted from [catppuccin/userstyles](https://github.com/catppuccin/userstyles) (Mocha + peach/mauve/sky pack conventions on top).

Install with [Stylus](https://add0n.com/stylus.html). Leave **Check for updates** ticked. Stylus updates when `@version` in the raw file is higher than the installed copy.

## Install everything

One Stylus install pulls every site style in this repo. Use **either** this pack **or** the per-site styles — not both (they would double-apply).

## Notes per style

**YouTube** imports the Catppuccin library from `userstyles.catppuccin.com` at apply time (LESS). Covers YouTube, Studio, and mobile. YouTube Music is self-contained and only matches `music.youtube.com`.

**Google** is one file: a shared Material token layer for `*.google.com` (login at `accounts.google.com` excluded), plus product blocks for Drive and Gemini. Gmail, Docs, Calendar, Keep, Photos, Meet, and Chat are next.

**Teams** matches `teams.cloud.microsoft` and `teams.microsoft.com`. It overrides Fluent v9 tokens (peach primary, mauve links and mentions, sky chat and channel names) and includes a small classic-shell block. Sign-in at `login.microsoftonline.com` is not themed. Set Teams to Dark, and enable Stylus CSP patching if the shell stays blue.

**OneDrive** matches `onedrive.live.com`, `photos.onedrive.com`, and every `{tenant}-my.sharepoint.com` host (OneDrive for Business, including `eduvosonline-my.sharepoint.com`). Team sites on `{tenant}.sharepoint.com` are not matched. File-type icons and photo thumbnails are left alone. Set OneDrive to Dark, and enable Stylus CSP patching if the shell stays blue.

**GitHub** matches `github.com` and `gist.github.com`. Peach primary buttons, mauve links, sky mentions/names.

**Grok** matches `grok.com`. Peach primary, mauve links, sky accents.

**Discord** matches `discord.com`. Imports the official Catppuccin Discord theme CSS (see the file header). Works best with Discord set to Dark.

**Spotify** matches `open.spotify.com`. Forces Mocha backgrounds on main surfaces, sidebar, and player bar (with `!important` to override Spotify's defaults). Peach primary/accent, mauve links, sky artist names. Works best with Spotify set to Dark.

**QuillBot** matches `quillbot.com` (and subdomains). Mocha shell (top bar + sidenav), peach primary (replaces brand green), mauve links. Main tools/editors forced to readable Mocha text (v1.0.2 paints main content grid (was pure white) with forced readable text; no upstream QuillBot userstyle found). Popups: MUI dialog/drawer(menu)/popover/tooltip/snackbar and OneTrust. No upstream Catppuccin userstyle yet. Enable Stylus CSP patching if sheets stay light.

**Claude** matches `claude.ai`. Forced Mocha dark (works even if Claude is set to light). Peach accent default. Token map from catppuccin/userstyles Claude 2026.11.01 (CDS surfaces, epitaxy, dframe, chat tokens). Older upstream-only installs often no-op because they require `data-mode` + an outdated lib import. Set Claude appearance to Dark if anything still flashes light. Popups/dialogs covered via `--cds-*` / portal tokens.

**DuckDuckGo** matches `duckduckgo.com` and `duck.ai`. Forced Mocha dark. Peach accent default. Token map from [catppuccin/userstyles](https://github.com/catppuccin/userstyles) DuckDuckGo 2026.09.18 (SDS + theme-col vars). Prefer DDG appearance Dark if anything flashes light.

**Stylus** themes the Stylus extension UI (manage, popup, editor) via `moz-extension://` / `chrome-extension://` URL prefixes (same approach as [catppuccin/userstyles](https://github.com/catppuccin/userstyles) Stylus 2026.08.16). Forced Mocha, peach accent. Set Stylus **UI theme** to Dark under Stylus settings if anything stays light. Note: extension URL prefixes can match other extensions that share similar CSS vars — disable if that conflicts.

**Proton** one style for Proton web apps: `mail`, `calendar`, `drive`, `account`, `pass`, `vpn`, `docs`, `photos`, `wallet`, `meet`, `lumo` on `*.proton.me`. Forced Mocha, peach accent. Token map from [catppuccin/userstyles](https://github.com/catppuccin/userstyles) Proton 2026.08.16 (`--background-*`, `--interaction-*`, mail/calendar optionals, logo recolor). Prefer Proton theme **Dark** if anything flashes light.

**Kick / Rumble** match `kick.com` / `rumble.com`. Peach / mauve / sky accents on Mocha base.

## Rebuild the Everything pack

Before adding or heavily rewriting a site style, check [catppuccin/userstyles](https://github.com/catppuccin/userstyles) for an existing port.

After editing any per-site `*.user.css`, regenerate the bundle (bump `VERSION` in the script when you want Stylus to auto-update the pack):

```bash
python3 scripts/build-all.py
```
